トラックと設定

トラック

    小節

    操作方法

    パソコン（マウス）

    • クリック：音符を追加（ドラッグで長さを決める）
    • ドラッグ：音符を移動 ／ 右端をドラッグで長さ変更
    • ダブルクリック・右クリック：削除
    • Shift+ドラッグ：範囲選択 ／ Shift+クリック：追加選択
    • Ctrl+ホイール：拡大縮小

    スマホ・タブレット（タッチ）

    • 指でなぞる：譜面をスクロール
    • 何もない所をタップ：音符を追加（選択中ならまず選択を解除）
    • 音符をタップ：選択
    • 選択した音符は上のボタンで移動・長さ変更・削除
    • トラックボタン：トラック・音色・強さの設定
    • 音が出ないときは、消音モード（マナーモード）を解除してください

    キーボード

    • Space：再生 / 停止 ／ Home：先頭へ ／ L：ループ
    • ↑ ↓：半音移動（Shiftで1オクターブ） ／ ← →：グリッド1つ分移動
    • Ctrl+Z / Ctrl+Shift+Z：元に戻す / やり直し
    • Ctrl+C / X / V / D：コピー / 切り取り / 貼り付け / 複製
    • Ctrl+A：すべて選択 ／ Q：グリッドに揃える

    共通

    • ルーラー（小節番号の帯）をタップ・クリック：再生位置 ／ ドラッグ：ループ範囲
    • 左の鍵盤欄をタップ・クリックすると音を試聴できます

    数字譜は唄用（ドレミ調）篠笛の表記です。「呂」は低い音域、「甲」は1オクターブ上、「大甲」はさらに上を表します。編集内容はブラウザに自動保存されます。
