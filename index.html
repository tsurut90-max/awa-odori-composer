    小節

    操作方法

    音符の編集

    • クリック：音符を追加（ドラッグで長さを決める）
    • ドラッグ：音符を移動 ／ 右端をドラッグで長さ変更
    • ダブルクリック・右クリック：削除
    • Shift+ドラッグ：範囲選択 ／ Shift+クリック：追加選択
    • ↑ ↓：半音移動（Shiftで1オクターブ）
    • ← →：グリッド1つ分移動
    • Q：グリッドに揃える

    再生・その他

    • Space：再生 / 停止 ／ Home：先頭へ
    • ルーラーをクリック：再生位置 ／ ドラッグ：ループ範囲
    • L：ループ切り替え
    • Ctrl+Z / Ctrl+Shift+Z：元に戻す / やり直し
    • Ctrl+C / X / V / D：コピー / 切り取り / 貼り付け / 複製
    • Ctrl+A：すべて選択 ／ Ctrl+ホイール：拡大縮小
    • 左の鍵盤欄をクリックすると音を試聴できます

    数字譜は唄用（ドレミ調）篠笛の表記です。「呂」は低い音域、「甲」は1オクターブ上、「大甲」はさらに上を表します。編集内容はブラウザに自動保存されます。
